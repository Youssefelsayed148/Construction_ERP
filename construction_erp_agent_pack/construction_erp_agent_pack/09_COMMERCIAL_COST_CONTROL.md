# 09 - Commercial, Contracts and Cost Control

## Contract directions
- Upstream: Client <-> Main Contractor
- Downstream: Main Contractor <-> Subcontractor
- Purchase: Main Contractor <-> Supplier

## Revenue model
Revised Contract Value = Original Contract Value + Approved Client Variations

Executed Value = value of measured work executed

Certified Revenue = consultant/client certified amount

Billed Revenue = invoices issued

Collected Revenue = allocated client receipts

Retention Receivable = certified retention not yet released

Accounts Receivable = billed - collected - credit notes/adjustments

## Cost model
Current Budget = Original Budget + Approved Budget Changes

Committed Cost = approved POs + subcontracts + other commitments less cancellations/committed reductions

Actual Cost = posted accepted costs according to accounting policy

Accrued Cost = incurred-not-invoiced estimated cost

ETC = forecast cost required to complete remaining scope

EAC = Actual Cost + Accrued Cost + ETC

Forecast Profit = Forecast Revenue - EAC

Forecast Margin % = Forecast Profit / Forecast Revenue * 100

## Cash metric separate from profit
Cash Contribution = Collections - Cash Payments
Do not label this project profit.

## Variation/change management
Change Event -> Potential Variation -> Cost/Schedule Analysis -> Internal Review -> Consultant Recommendation -> Client Approval -> VO.

Track:
- cause
- responsibility
- linked RFI/instruction/drawing
- submitted/recommended/approved value
- days impact
- revenue impact
- cost impact

## Subcontract commercial
Original Subcontract + Approved Changes = Revised Subcontract

Track:
- executed
- certified
- retention
- advance recovery
- previous paid
- current due
- paid/outstanding
