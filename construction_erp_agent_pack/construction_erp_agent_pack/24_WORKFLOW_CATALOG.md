# 24 - Workflow Catalog

## Workflow engine features
- sequential steps
- parallel steps
- role/organization resolver
- conditional amount thresholds
- required attachments/comments
- due dates/SLA
- delegation
- escalation
- return/rework loops
- cancellation/void reason
- audit trail

## Standard workflows
### RFI
Draft -> Submitted -> Coordinator -> Discipline Reviewer(s) -> Official Response -> Acknowledged -> Closed

### Submittal
Draft -> Internal Technical Review -> PM -> Consultant Coordinator -> Reviewer(s) -> Response -> Resubmit/Close

### Consultant Observation
Raised -> Acknowledged -> Assigned -> Rectification -> Verification Requested -> Accepted/Rejected -> Closed

### WIR
Draft -> QA/QC -> PM optional -> Consultant -> Approved/Comments/Rejected/Reinspect

### MIR
Delivery -> Internal QA/QC -> Consultant if required -> Accepted/Rejected/Quarantine -> GRN eligibility

### NCR
Open -> Assigned -> Root Cause/Corrective Action -> Verification -> Resolved -> Closed; reopen permission controlled

### Purchase Requisition
Draft -> Submit -> Budget Check -> Authority Approval -> Procurement

### PO
Draft -> Commercial/Procurement Approval -> Financial Authority -> Issued -> Acknowledged -> Partially/Fully Delivered -> Closed

### Variation
Change Event -> Estimate -> Internal Commercial Review -> Authority Approval -> Consultant Recommendation -> Client Approval/Reject -> Incorporated

### Payment Certificate
Draft Measurement -> QS Review -> PM/Commercial -> Consultant/Client -> Certified -> Invoice Eligible

### Supplier/Subcontract Invoice
Received -> Match/Certificate -> AP Review -> Approval -> Due -> Paid

### Handover Punch
Raised -> Assigned -> Rectified -> Verified -> Closed
