# 16 - Document Control, RFI, Submittals and Correspondence

## Controlled document register
Fields:
- document number
- title
- project
- discipline
- type
- location/package
- originator
- revision
- status
- issue date
- review due
- confidentiality/visibility

## Revision rules
- exactly one current revision per controlled document
- previous revisions immutable/superseded
- superseded files display a prominent warning
- new revision may reset review/approval according to workflow

## Transmittals
Track incoming/outgoing documents, recipients, purpose, acknowledgement and response due dates.
Generate branded PDF transmittal.

## Correspondence
Formal letters/notices/instructions/claims:
- unique number
- sender/recipient organization
- subject
- linked contract/project record
- due/response date
- attachments
- audit trail

## RFI
Fields:
- subject/question
- project/location/work package
- discipline
- drawing/spec references
- photos/files
- priority
- due date
- cost impact flag/value optional
- schedule impact flag/days optional

Workflow:
Draft -> Submitted -> Coordinator Review -> Discipline Reviewer(s) -> Official Response -> Contractor Acknowledgement -> Closed.

## Submittal
Types:
- material
- shop drawing
- sample
- method statement
- mock-up
- technical data
- test certificate

Track package, revision, reviewers and response code.
Suggested response codes configurable, e.g. Approved / Approved with Comments / Revise & Resubmit / Rejected.

## Search
Search current and historical revisions, transmittals, RFIs and correspondence subject to permission.
