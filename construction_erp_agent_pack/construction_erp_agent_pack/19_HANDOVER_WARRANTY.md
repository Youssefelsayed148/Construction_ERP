# 19 - Handover, Closeout and Warranty

## Handover workflow
Pre-Handover -> Punch/Snag -> Rectification -> Final Inspection -> Testing & Commissioning -> As-Builts -> O&M -> Training -> Taking Over -> DLP/Warranty -> Final Completion.

## Punch item
- project/location/asset
- discipline
- description
- photos
- responsible subcontractor
- due date
- verification authority

## Handover package
Register:
- as-built drawings
- O&M manuals
- warranties
- test/commissioning results
- certificates
- equipment/asset register
- keys/access items
- training records
- authority approvals

## Asset register
Installed equipment/system:
- asset code
- location
- model/serial
- supplier
- subcontractor
- commissioning date
- warranty start/end
- documents

## Warranty/DLP claim
Client/authorized user raises claim linked to asset/location. Route to PM/subcontractor, track SLA, rectification evidence and acceptance.
