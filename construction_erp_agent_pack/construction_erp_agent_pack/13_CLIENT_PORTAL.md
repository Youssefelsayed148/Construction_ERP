# 13 - Client / Owner Portal

## Design principle
Executive, clean and highly permission-controlled. No internal subcontract/supplier prices unless explicitly permitted.

## Dashboard
- project health
- overall progress
- planned vs actual
- milestones
- high-level schedule
- latest progress photos
- approved/pending variations
- client approvals required
- certified/billed/paid/outstanding values
- owner-facing documents
- weekly/monthly reports
- handover readiness

## Client action center
- approvals
- decisions
- variation responses
- document acknowledgements
- overdue owner inputs

## Portfolio view
If client has multiple projects, first page is portfolio with project health and key metrics.

## Zero-data/zero-client requirement
Internal preview route must always work even before a client organization or portal user is assigned. Show setup actions rather than an error.

## Preview mode
Authorized internal admin/PM can Preview as Client without creating a fake account. Preview is read-only and audited.
