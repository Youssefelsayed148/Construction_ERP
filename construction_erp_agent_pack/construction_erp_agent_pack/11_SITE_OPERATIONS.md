# 11 - Site Operations

## Site engineer daily workspace
- today's activities
- current location/floor
- latest approved drawings
- work orders
- inspections due
- consultant observations assigned
- material readiness
- manpower
- equipment
- deliveries
- safety actions
- daily report
- quick photo capture

## Daily report
Auto-populate from source records where possible:
- date/weather integration optional
- active schedule/work-order activities
- manpower/time records
- equipment usage
- deliveries/GRNs
- executed quantities
- inspections
- observations
- photos

User adds narrative, issues, blockers and next-day plan.

## Site visit
Formal visit record:
- visit number
- project/location
- visitor organization/user/role
- visit type
- attendees
- purpose
- inspected activities
- referenced drawings/documents
- notes
- photos
- observations/action items

## Observation
Each consultant/construction-manager comment becomes a trackable record:
- observation number
- exact location
- discipline/category
- priority
- comment
- reference drawing/spec
- before photos
- assignee
- due date
- status

Workflow:
Raised -> Acknowledged -> Assigned -> Rectification In Progress -> Submitted for Verification -> Accepted/Rejected -> Closed.

On create:
- notify project manager
- create PM action
- allow PM assignment to site engineer/subcontractor

On rectification:
- capture after photos and comments

On consultant rejection:
- reopen/return action with new comment and audit trail
